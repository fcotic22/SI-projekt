# SI projekt - web verzija

Pokretanje:

```bash
pip install -r requirements.txt
python app.py
```

Otvoriti u pregledniku:

```text
http://127.0.0.1:5000
```

Kod koristi ključnu riječ `.tie5Roanl`. Kod unosa treba upisati točno tu riječ i završiti tipkom Enter.

## Napomena o staroj terminal verziji

Datoteka `KeystrokeDynamics_terminal.py` sadrži izvornu terminal/konzolnu verziju programa. Web aplikacija se pokreće preko `app.py`, a terminal verzija je ostavljena kao referenca da se vidi izvorna logika prikupljanja unosa, registracije i prijave.
